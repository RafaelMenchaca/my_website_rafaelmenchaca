# Rafael Menchaca Developer Portfolio

Personal developer portfolio built with Next.js.

This project showcases backend-focused work with an emphasis on AI-powered
systems, clean architecture, and real-world applications.

## Tech Stack

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS v4
- react-icons

## Routes

- `/` Home
- `/about` Developer profile and focus
- `/projects` Selected projects
- `/projects/[slug]` Detailed case studies
- `/contact` Contact page

## Local Development

```bash
npm install
npm run dev
```

## Notes

This portfolio is intended to stay minimal, clear, and easy to extend as new
projects and case studies are added.
