# Rafael Menchaca – Developer Portfolio

Personal developer portfolio built with Next.js.

This project showcases my work as a backend-focused developer, with an emphasis on AI-powered systems, clean architecture, and real-world applications.

## Tech Stack
- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS

## Structure
- `/` – Home
- `/about` – Developer profile and focus
- `/projects` – Selected projects
- `/projects/[slug]` – Detailed case studies

## Featured Project
**Educativo IA**  
An AI-powered educational platform focused on backend architecture, AI integration, and structured data workflows.

## Notes
This portfolio is a living project and will evolve as new projects and features are added.
